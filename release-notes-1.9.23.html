nox 1.9.23

Polish + stability pass.

  • Drop picker re-styled. Removed the circular chips around the Save / AirDrop icons (felt heavy, not Apple-like). Bare 36pt SF Symbol with hierarchical rendering for subtle depth, soft accent glow on hover, thin accent hairline along the bottom edge of the hovered zone as the commit affordance.
  • Drop-to-Images no longer freezes. When you drop an image onto Save, the auto-switch to the Images tab now defers 200ms so the open morph completes before the heavy ImagesGridView mounts. Reads as a smooth tab swap instead of a brief stall.
  • Drag-out jitter gone. Dragging an image FROM the grid out to another app used to trigger the system drag monitor to repeatedly re-publish the Images tab, causing micro-stutter during the drag. Added an idempotent guard so re-arming the same tab is a no-op.
  • MediaRemote dedup. Spotify's two-stage publish (metadata then bytes) and MediaRemote's metadata-refresh re-emissions used to fire the SwiftUI body re-evaluation twice per track tick. Now collapsed via a 50ms time-based dedup (mirrors Alcove’s liveActivitySwapDebounce). Cuts pill-refresh body cost roughly in half during music playback.
  • Dictation waveforms only tick when active. The recording and processing waveforms used to keep their 30Hz TimelineViews ticking even when the pill was in a different phase. Now paused unless their phase is active.
  • HoverActivator no-op in Release. Removed the synchronous syslog calls in the hover hot path that fired on every display reconfigure (Continuity / AirPlay / fullscreen). Compiled out in Release.

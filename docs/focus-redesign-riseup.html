What's different from the current panel

  • One card, not four. The hero / today-tile / week-tile / controls stack collapses into a single composed card. Less visual fragmentation, more breathing room around what matters.
  • Goal-first framing. "Focus at least 60 min today" gives every number on the card a purpose. Without a goal, "23 min today" is just a number — with one, it's progress toward something.
  • Per-day rings replace the bar sparkline. Each ring fills proportionally to how close that day was to the goal. Filled = hit. Partial = progress. Empty = miss. Reads at-a-glance the way the bar chart never did.
  • Today is pill-highlighted. Subtle border + brighter accent on the time. Eye lands on "Thu" without scanning.
  • Footer aggregates instead of repeating. Total this week + Avg daily + a hero ring artwork = three pieces of info, no competing focal points.
  • Controls drop to a thin strip below. The toggles aren't the headline — the data is. Toggles get smaller iconographic rows so they read as utility, not main content.
  • "Daily goal" becomes a tappable row. Currently we hardcode 60 min. Letting the user set their own goal makes the rings personal, not arbitrary.

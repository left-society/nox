4 · Behaviors / controls

What clicks, what keys, what stops it
  • Start: button in Script tab editor — pill morphs from resting → teleprompter
  • Pause / resume: spacebar globally OR click the pill
  • Speed: WPM slider in the editor (80–250 WPM range, default 150)
  • Manual scrub: two-finger trackpad scroll over the pill — overrides auto-scroll
  • Stop: Esc — pill morphs back to resting (music or focus)
  • Auto-stop: hits the end of the script — pill morphs back; brief "✓ Done" flash before it shrinks
  • Hotkey to start: ⌥⇧S (configurable later)
  • Save state: if you close nox while reading, position is saved; reopening restores at last word

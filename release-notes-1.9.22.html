nox 1.9.22

Bug fixes and touch-feel polish.

  • Slab no longer opens by itself. Fixed the spurious open that fired on app close, iPhone Continuity events, and background app launches (the dwell-timer was resetting hover state during display flux).
  • YouTube and Chrome play / pause work reliably. Browser media keys now use a synchronous AppleScript bridge with real status return; falls through to the system adapter on permission denial.
  • No-music notch pill touch feel. Tease size, spring (988 / 63 critical), and silhouette corners calibrated to a measured reference; rate-limited to stop continuous-cursor churn.
  • Close gesture: no more stutter. Switched the close animator off CVDisplayLink (which was hopping threads) onto a main-runloop CADisplayLink spring at 438 / 42 critical damping. Squarish-corner artifact during close also fixed.
  • Pill artwork no longer “comes from down-right” on close. The matched-geometry effect that caused it has been removed; the pill content is now always-mounted so it doesn’t fade in from an offset.
  • Live tab switch-back is instant. The music panel is now always-mounted in a ZStack so coming back to Live from another tab no longer re-mounts the whole tree.
  • Settings window opens instantly. Pre-warmed in the background 3s after launch.
  • Other: production menu cleanup (debug “Test pill” hidden), dictation drag-and-drop perf, first-launch warmup pass.

Note: this release rotates the Sparkle update-signing key. Existing v1.9.21 installs cannot auto-update to v1.9.22 because their bundled key won’t verify the new signature — please redownload from trynox.app once. All future updates resume normal auto-updating.

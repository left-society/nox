nox 1.9.27

Cumulative fixes since 1.9.24 — multi-monitor stability, smarter drag detection, cleaner drop picker.

  • Drop picker redesign. Fully transparent at rest (no card silhouette, no detached corners). On hover, the chosen side fills with a soft accent-tinted rectangle that follows the slab’s own outer curve. No borders, no glow, no chrome — the fill is the entire commit affordance.
  • Multi-monitor: slab stays on the MacBook. Previously the panel chased the cursor between displays whenever a screen-params event fired. Now it always lands on the notched display unconditionally (falls through to the active display only in clamshell mode).
  • Music pill stays on the MacBook too. The resting notch HUD was positioning on whichever display was set as “primary” in System Settings. Fixed — it now follows the actual notch hardware.
  • Drag-anywhere no longer wakes the panel. Dragging files in unrelated apps (Finder windows, external displays) used to pop the nox panel open via the system drag-pasteboard watcher. Added a cursor-position gate so the panel only wakes when the cursor is near the notch on the MacBook display.
  • Default tab on open: Live. New default. The slab lands on the Live tab (now playing, Focus, Study, calendar) every time you open. If you prefer the previous “last tab wins” behavior, set Settings → General → Default tab → Last.
  • No-music notch hot zone narrowed. Previously a generous 300pt zone that fired on cursor passes well past the notch edges. Now uses the actual notch hardware width when no music pill is visible, widens automatically when music is playing (covers the pill).
  • Post-drop tab switch deferred. When you drop an image, the auto-switch to the Images tab waits ~200ms so the open animation completes before the heavy grid mounts. Smooth swap instead of a brief stall.
  • Stability under load. MediaRemote duplicate emits collapsed via a 50ms dedup (kills Spotify’s two-stage publish double-fires). Dictation waveform TimelineViews pause when their phase isn’t active. HoverActivator NSLog calls compiled out of Release builds.
